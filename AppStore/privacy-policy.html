OceanCheck — Privacy Policy

Effective date: March 2026  |  Last updated: 20 March 2026

This privacy policy describes how the OceanCheck mobile application ("App"), operated by Seapay Ltd. ("we", "us", "our"), collects, uses, and protects information when you use the App.

Seapay Ltd.

2. Information We Collect

The App processes the following categories of data:

  • Identity documents: Photos or scans of passports, ID cards, driver licenses, and residence permits uploaded by the agent for verification purposes.
  • Personal information extracted from documents: Full name, date of birth, nationality, document number, expiry date, address, and gender — extracted automatically via optical character recognition (OCR).
  • Proof of address documents: Utility bills, bank statements, or official letters uploaded for address verification.
  • Agent information: The name entered during setup, used for audit trails and PDF reports.
  • Location data: GPS coordinates captured at the time of verification, if permission is granted, for audit purposes.
  • API key: Your verification service API key, stored securely in the iOS Keychain.

3. How Data Is Processed

  • Document images are sent to third-party identity verification APIs for processing (OCR extraction, document authenticity checks, AML/sanctions screening).
  • Personal data extracted from documents is used to perform anti-money laundering (AML) screening against global sanctions, PEP, and adverse media databases.
  • Verification results and agent notes are stored locally on the device.
  • PDF reports are generated locally on the device and shared only when the agent explicitly chooses to export them.

4. Data Storage

  • On device: Verification records, captured images, agent notes, and PDF reports are stored in the app's sandboxed Documents directory on the iOS device. The API key is stored in the iOS Keychain with device-only access protection.
  • No cloud storage: The App does not upload data to any cloud storage, analytics service, or backend server operated by Seapay Ltd.
  • Third-party processing: Document images and extracted personal data are transmitted to the identity verification API provider for processing. This data is subject to the provider's data processing terms.

5. Data Retention

  • All data stored on the device persists until the agent deletes individual checks or performs a full reset from the Settings screen.
  • Data transmitted to third-party verification APIs is retained according to the API provider's retention policies.
  • The App does not implement automatic data expiration. Agents are responsible for managing data retention in accordance with their organisation's policies.

6. Data Sharing

We do not sell, rent, or share personal data with third parties except:

  • With the identity verification API provider, as necessary to perform the verification services requested by the agent.
  • When the agent explicitly exports a PDF report and shares it via the iOS share sheet.

7. Your Rights

Under applicable data protection legislation (including UK GDPR), you have the right to:

  • Access the personal data we process
  • Request correction of inaccurate data
  • Request deletion of your data
  • Object to or restrict processing
  • Data portability

Since all verification data is stored locally on the agent's device, data subject requests should be directed to the organisation operating the device. For requests relating to data transmitted to the verification API, contact the API provider directly.

8. Security

  • API keys are stored in the iOS Keychain with kSecAttrAccessibleWhenUnlockedThisDeviceOnly protection.
  • All network communication uses HTTPS/TLS encryption.
  • Document images are stored in the app's sandboxed file system, inaccessible to other apps.
  • No analytics, crash reporting, or tracking SDKs are included in the App.

9. Children's Privacy

The App is not intended for use by individuals under the age of 18. We do not knowingly collect personal data from children.

10. Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above. Continued use of the App after changes constitutes acceptance of the revised policy.
