OceanCheck — Privacy Policy

Effective date: March 2026  |  Last updated: 22 March 2026

This privacy policy describes how the OceanCheck mobile application ("App"), operated by Nave Magna Ltd. trading as SeaPay ("we", "us", "our"), collects, uses, and protects information when you use the App.

Nave Magna Ltd. (trading as SeaPay)

2. Information We Collect

The App processes the following categories of data:

  • Identity documents: Photos or scans of passports, ID cards, driver licenses, residence permits, and maritime certificates uploaded for verification and compliance tracking.
  • Personal information extracted from documents: Full name, date of birth, nationality, document number, expiry date, address, and gender — extracted automatically via optical character recognition (OCR).
  • Maritime certificates: STCW certificates, Certificates of Competency, medical certificates (ENG1/PEME), flag state endorsements, and other maritime qualifications — photographed and tracked with expiry dates.
  • Vessel information: Vessel name, IMO number, flag state, port of registry, vessel type, and vessel certificates — entered manually or extracted via OCR from Certificates of Registry.
  • Corporate information: Company names, registration numbers, jurisdictions, and beneficial ownership percentages for entity verification (ship owners, UBOs, management companies).
  • Proof of address documents: Utility bills, bank statements, or official letters uploaded for address verification.
  • Agent information: The compliance officer's name entered during setup, used for audit trails and PDF reports.
  • Location data: GPS coordinates captured at the time of verification, if permission is granted, for audit trail purposes.
  • API key: Your verification service API key, stored securely in the iOS Keychain.
  • Profile photos: Automatically extracted from passport scans or captured separately for crew identification.

3. How Data Is Processed

  • Identity document images are sent to third-party identity verification APIs for processing (OCR extraction, document authenticity checks, AML/sanctions screening).
  • Personal data extracted from documents is used to perform anti-money laundering (AML) screening against global sanctions, PEP, and adverse media databases.
  • Maritime certificate images are stored locally only — they are NOT sent to any external service. They are tracked for expiry management purposes.
  • Vessel Certificate of Registry documents are processed locally using on-device OCR (Apple Vision framework) — no external transmission.
  • Verification results, agent notes, and crew/vessel data are stored locally on the device.
  • PDF compliance reports and CSV exports are generated locally on the device and shared only when the agent explicitly chooses to export them.
  • Push notifications for document expiry are scheduled locally using iOS notification services — no external push notification service is used.

4. Data Storage

  • On device: All verification records, captured images, maritime certificates, vessel data, crew data, agent notes, and generated reports are stored in the app's sandboxed Documents directory on the iOS device.
  • Keychain: The API key and workflow ID are stored in the iOS Keychain with device-only access protection.
  • Backup files: When the agent exports a backup, all data is packaged into a ZIP file and shared via the iOS share sheet. The backup file destination is controlled entirely by the agent.
  • No cloud storage: The App does not upload data to any cloud storage, analytics service, or backend server operated by Nave Magna Ltd.
  • Third-party processing: Identity document images and extracted personal data are transmitted to the identity verification API provider (Didit, https://didit.me) for processing. This data is subject to the provider's data processing terms.

5. Data Retention

  • All data stored on the device persists until the agent deletes individual checks, vessels, or documents, or performs a full reset from the Settings screen.
  • Data transmitted to third-party verification APIs is retained according to the API provider's retention policies.
  • The App provides document expiry tracking and notifications but does not automatically delete expired records. Agents are responsible for managing data retention in accordance with their organisation's policies and applicable maritime regulations.

6. Data Sharing

We do not sell, rent, or share personal data with third parties except:

  • With the identity verification API provider (Didit), as necessary to perform the identity verification and AML screening services requested by the agent.
  • When the agent explicitly exports data via PDF reports, CSV files, compliance packets, or backup files using the iOS share sheet.
  • When crew members complete self-verification via a shared link, their document and biometric data is processed by the verification API provider directly — the agent's device receives only the verification decision and extracted data.

7. Your Rights

Under applicable data protection legislation (including UK GDPR), you have the right to:

  • Access the personal data we process
  • Request correction of inaccurate data
  • Request deletion of your data
  • Object to or restrict processing
  • Data portability

Since all verification data is stored locally on the agent's device, data subject requests should be directed to the organisation operating the device. For requests relating to data transmitted to the verification API, contact the API provider directly.

8. Security

  • API keys are stored in the iOS Keychain with kSecAttrAccessibleWhenUnlockedThisDeviceOnly protection.
  • All network communication uses HTTPS/TLS encryption.
  • Document images are stored in the app's sandboxed file system, inaccessible to other apps.
  • PDF reports include SHA-256 integrity hashes for tamper detection.
  • On-device OCR processing (Certificate of Registry scanning) does not transmit data externally.
  • No analytics, crash reporting, or tracking SDKs are included in the App.

9. Children's Privacy

The App is not intended for use by individuals under the age of 18. We do not knowingly collect personal data from children.

10. International Data Transfers

When identity documents are submitted for verification, data may be transferred to the verification API provider's servers, which may be located outside the United Kingdom or European Economic Area. Such transfers are made in accordance with applicable data protection legislation and the API provider's data processing terms.

11. Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above. Continued use of the App after changes constitutes acceptance of the revised policy.
